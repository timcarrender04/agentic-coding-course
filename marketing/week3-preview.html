Week 3 · Terminal Core

Module 01 · Files, Sudo & Permissions
Build and destroy from the keyboard, edit files without a mouse, and crack the permissions grid.
Mon Aug 3 + Wed Aug 5  ·  6:00–8:00 PM  ·  Zoom  ·  Labs 01:02–06

This week is pure terminal. Monday we build ~/docker-course/, edit files with nano, run your first sudo system update, install Docker’s prerequisites — then the boss fight: permissions. Wednesday’s clinic is mostly reserved for chmod/chown drills. Labs — not attendance — gate progress.

Week goals

1

Build & destroy

mkdir, touch, cp, mv — and your first careful rm -r. No undo exists.

2

Read & edit

cat, less, tail -f, nano. Exit keys memorized: q, Ctrl+O, Ctrl+X.

3

Sudo & install

apt update / upgrade clean, then install the Docker prerequisite packages.

4

Permissions

Read -rwxr-x--- out loud and say who can do what. chmod + chown without guessing.

Before Monday
  • Module 00 gate screenshot must be in D2L
  • Finish labs 01:00–01 (setup check + pwd/ls/cd)
  • Confirm your remote still connects — green WSL or SSH badge
  • Watch the Module 01 videos for 02–06 if posted in D2L
  • Bring laptop + charger + your sudo/Linux password
Know before you type
  • rm -r has no undo — read the path twice, then read it again
  • Password prompts type invisibly — keep typing, press Enter
  • less and top aren’t frozen — press q to quit
  • nano saves with Ctrl+O, exits with Ctrl+X

Stuck-spot cheat sheet

MomentWhat failsFix line
rm -r Scared to run it / wrong path No undo exists. Read the path you typed, then read it again — then run it
less / top “My terminal is frozen” It’s a pager, not a freeze — press q to quit
nano Can’t save or get out Ctrl+O then Enter to save · Ctrl+X to exit — arrows won’t escape
tail -f Looks stuck doing nothing It’s waiting for new lines. Open a second terminal and echo into the file — watch it appear
apt “Could not get lock / dpkg lock” Another apt process is running — wait it out; don’t kill it unless truly stuck
chown “Operation not permitted” You forgot sudo. Everyone does it once — that’s the lesson
chmod Tempted to type 777 Never on a real server — it means anyone can do anything. Set only what’s needed
