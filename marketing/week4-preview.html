Stuck-spot cheat sheet

MomentWhat failsFix line
ping / top “Terminal won’t give me my prompt back” Ctrl+C stops ping · q quits top/htop — not frozen
curl / dig DNS or Hub unreachable Check Wi-Fi/VPN first · then ping 8.8.8.8 vs ping google.com (IP vs DNS)
systemctl ssh.service missing on WSL Expected on many WSL setups — systemctl is-active cron counting as pass
pipes Empty output / weird errors Build left→right one stage at a time; confirm each piece alone before adding |
usermod group 'docker' does not exist That’s the lesson. Docker creates the group in Module 02 — screenshot the error
phase-gate Blank on a command No help during the timed run — reopen the matching lesson after, then re-attempt
After Wednesday → Sunday: labs 01:07–11 submitted in D2L (gate included). Minimum comfort: you can prove network + process health, build a pipe with grep, and explain why the docker usermod failed. Next week: Module 02 — install Docker Engine and run your first containers.
