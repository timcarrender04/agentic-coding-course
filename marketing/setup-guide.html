Monday is an intro & setup session

The first live block is a welcome session, not a lecture you can fall behind in. We'll walk through how the course works, tour D2L Brightspace (the online platform where every video, lesson, and lab submission lives), and then set up every laptop together — installing VS Code, adding the right extensions, and getting Windows machines scheduled for WSL (Ubuntu Linux). What your computer needs

Everyone: a 64-bit laptop with 8 GB RAM (16 GB recommended), 30 GB free disk, reliable internet, and administrator rights to install software. No GPU required — the AI runs on college hardware.
Windows Windows 10 / 11 + WSL2
  • Windows 10 (version 2004 / build 19041 or later) or any Windows 11.
  • WSL2 with Ubuntu — installed in Module 00 (or at home, page 3). Expect one reboot.
  • Hardware virtualization enabled in BIOS/UEFI (usually already on).
  • Fallback: if WSL2 won't work, do the whole course over SSH into the college's Linux server.
Mac macOS — Apple Silicon or Intel
  • macOS 12 Monterey or later — Apple Silicon (M1–M4) and Intel Macs are both fine.
  • Uses the built-in Terminal — no WSL or extra setup needed for a Unix shell.
  • VS Code, Docker Desktop, and all developer tools install natively.
  • For Ubuntu-specific drills (apt, services), you'll SSH into the college's Linux server.
Not supported: Chromebooks and tablets (including iPads) — this course needs a laptop you can install software on. If that's your situation, email the instructor before Monday and we'll figure out an option.

Optional head start #1 — install VS Code (all students, ~5 min)

  1. Go to code.visualstudio.com and download the installer for your system.
  2. Run it and accept the defaults. If it offers to "sign in to sync settings," you can skip that.
  3. That's it — don't install any extensions yet; we do that together Monday.

Optional head start #2 — install WSL2 + Ubuntu (confident Windows users, ~20 min + reboot)

  1. Right-click the Start button → Terminal (Admin) or PowerShell (Admin).
  2. Type wsl --install and press Enter, then reboot when asked.
  3. After the reboot, Ubuntu asks you to create a username (short, lowercase) and a password — the password is invisible while you type; that's normal. Write both down.
  4. If anything goes wrong, stop and bring it Monday — that's exactly what the first sessions are for.
Please don't install ahead: Docker, Continue.dev, or any AI/extension bundles. We install each one together at the right moment, configured the way the course needs it — installing early usually creates cleanup work, not a head start.
