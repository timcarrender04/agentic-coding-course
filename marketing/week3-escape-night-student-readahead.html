Terminal Escape Night

"Lockdown at ChiefOS" · Read this before class
No lecture tonight. Four locked rooms, a dead GUI, and a race — your keyboard is the only key.
Wed Aug 5  ·  6:00–8:00 PM  ·  Zoom  ·  Setup required BEFORE class

The story: a bad update has locked every door in the ChiefOS server building at 23:47 — and you're inside. Mouse dead. GUI dead. Terminal only. You'll fight through four escape rooms, each guarding one code word. Collect all four, write the escape plan, and get out. Every room is solvable with commands you already used in labs 01:02–06. Nothing new is required — tonight tests whether the week stuck. The answer to every puzzle is written down inside the game. Read the room. It always tells you.

Do this BEFORE 6:00 PM — required
  1. Download setup.sh from D2L (Week 3 → Escape Night)
  2. In your WSL/Ubuntu terminal, run: bash setup.sh
    — as yourself, never sudo bash setup.sh
  3. It asks for your password once, near the end. The prompt types invisibly — keep typing, press Enter
  4. Verify: ls ~/escape-night shows four room folders + README
  5. Don't go in yet. Exploring early is cheating yourself out of the race
Bring to class
  • Laptop + charger + your sudo/Linux password
  • Know how to open a second terminal window — one room needs two at once
  • Your notes from Monday — tonight is open-notes, and page 2 of this handout is a legal cheat sheet
  • Labs 01:02–05 finished if possible — the game assumes those muscles
  • Setup didn't work? Arrive at 6:00 sharp — that's the fix-it window

How the race works

TEAMS

3 teams · 6 pods

Team SUDO, Team NANO, Team CHMOD — each split into two pods of 4–5, each pod in its own Zoom breakout room. Your team's score is the sum of both pods.

ROLES

Rotate every room

Driver shares screen and types while narrating · Reader reads the room's files aloud · Scribe tracks code words and posts clears in main chat. Everyone else: eyes on for typos.

RULE #1

Nobody rides along

Everyone types every room on their own machine. A pod clears a room only when every member has the code word. Finished early? Coach with words — never touch a teammate's keyboard.

Scoring
  • Each room pays points by pod finish order: 6·5·4·3·2·1
  • The final escape pays double
  • Team score = pod A + pod B — a slow start can still win the vault
  • Winning team gets bragging rights + first pick of debrief topic
Hints
  • Your pod has 1 hint token for the whole night — spend it wisely (Zoom "Ask for Help" summons the instructor)
  • Unlimited free hint, always the same: read the room's files again — the answer is written down. It always is.
  • The game itself talks back: when something doesn't work, it prints why. Read the message before asking

Train before tonight — the seven escape skills

If you can do these seven things, you can escape. Each one comes straight from a lab you've already done. Rusty on any? Re-run that lab this afternoon — that's the whole read-ahead assignment.

#Can you…Practice commandsFrom lab
1Move around and look inside things without a mousepwd · ls · cd · cd .. · cat01:01–02
2Build, copy, rename, and carefully destroymkdir · cp · mv · rm -r01:02
3Page through a long file — and get back outless file  (space = next, q = quit)01:03
4Watch a file update live in a second terminaltail -f file  (Ctrl+C to stop)01:03
5Edit, save, and exit in nano — no panicnano file · Ctrl+O, Enter · Ctrl+X01:03
6Use sudo when the system says you can'tsudo whoami · sudo chown01:04, 01:06
7Read an ls -l permission string and change itls -l · chmod · chmod +x01:06
Skill 7 is the boss fight. Practice reading -rwxr-x--- out loud: owner can read/write/run · group can read/run · everyone else — nothing. If you can say that sentence for any listing, the vault will not stop you. This is also the exact skill next week's Module 01 phase-gate tests.

Rules of the building

Fair play
  • Don't enter ~/escape-night before the race starts
  • Coach teammates with words only — never type on someone else's machine, never screen-share an answer
  • No web searches needed or allowed — everything is in the rooms and on this page
  • Notes, this handout, and your lab files: all legal
Safety
  • Everything happens inside ~/escape-night/ — the game never asks you to touch anything outside it
  • The game contains exactly one rm -r. Same ritual as lab: read the path twice, then read it again
  • Wrecked your room? bash setup.sh --reset rebuilds it fresh in seconds — you only lose time, never your computer

What "escaped" looks like

The final door prints a victory banner in your terminal. Screenshot it and post it in Zoom chat — that's tonight's participation artifact, and it's how your pod proves its clears. Then be ready to read one ls -l line out loud in the debrief. That's the exit ticket.

Still owe labs? Tonight IS the review. Everything you type in the escape room is labs 01:02–06 material — finish and submit those in D2L by Sunday. Labs, not attendance, gate your progress to Week 4.
