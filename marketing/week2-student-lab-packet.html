Week 2 · Remote + Gate

Module 00 Finish → Terminal Start
Connect to a real Linux environment, pass the Module 00 phase-gate, then take your first terminal steps.
Mon + Wed  ·  6:00–8:00 PM  ·  Zoom  ·  Labs 00:05–07 (+ 01:00–01)

This week closes Module 00. Monday we connect Windows to WSL, everyone to the college server over SSH, and walk the Module 00 phase-gate live. Wednesday is a clinic for screenshots, connection issues, and (if you’re ready) the first Ubuntu terminal labs. Labs — not attendance — gate progress.

Week goals

1

WSL green

Windows: bottom-left shows WSL: Ubuntu. Mac/Linux: native shell + uname -a.

2

SSH connected

Green SSH: hostname. hostname + whoami match the remote — not your laptop.

3

Gate submitted

One screenshot: green badge + whoami + pwd in the remote terminal.

4

Terminal ready

Stretch / Wed: Module 01 setup check + pwd / ls / cd.

Before Monday
  • Finish labs 00:00–04 if anything is still open
  • Windows: run wsl --install at home and reboot before class
  • Install extensions if missing: WSL + Remote - SSH (Microsoft)
  • Bring laptop + charger + admin / Linux password
  • Watch Module 00 videos for 05–07 if posted in D2L
Bring to class
  • Any stuck screenshot or error from Week 1
  • Whether you’re on Windows, Mac, or Ubuntu
  • Notebook for the SSH host / user the instructor posts
  • Patience — first SSH connection asks you to type yes
  • Laptop charger (sessions run ~2 hours)

Stuck-spot cheat sheet

MomentWhat failsFix line
WSL Needs reboot / blank password Reboot after wsl --install. Password typing is invisible — keep typing, then Enter
Badge Opened C:\Users\… Not connected. Reconnect → green WSL: Ubuntu → open /home/…
SSH first Fingerprint prompt stalls Type yes (Enter alone does nothing — there is no default)
SSH key UNPROTECTED PRIVATE KEY Windows: lock key permissions to your user only · or keep the key inside WSL
Paste Host string has curly quotes Paste from chat / plain text only — never from Word or styled email
After SSH “My local files vanished” Expected — every terminal/file is on the remote until you Close Remote Connection
Gate Stuck mid-checkpoint Re-read the lesson — no instructor help during the 15-minute block. Ask after time’s up
After Wednesday → Sunday: Module 00 gate must be in D2L. If you started Module 01, finish 01:00–01. Don’t rush ahead into sudo/permissions yet — that’s Week 3. Minimum comfort: green remote badge, gate screenshot submitted, you can pwd/cd without panic.
