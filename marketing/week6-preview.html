Know before you type
  • We want Docker Engine (Linux daemon), not Docker Desktop
  • permission denied … docker.sock → log out / newgrp docker
  • WSL: if systemctl fails, sudo service docker start
  • Forgot -d? Terminal “hangs” — nginx is in the foreground. Ctrl+C, re-run

Stuck-spot cheat sheet

MomentWhat failsFix line
install GPG / apt-repo step “did nothing” Don’t skip steps. Confirm which gpg before the dearmor; Hub must be reachable
docker.sock permission denied while trying to connect to the Docker daemon socket You are not in the group yet in this shell — newgrp docker or log out / back in
WSL start systemctl: “System has not been booted with systemd” sudo service docker start — add it to ~/.bashrc so it survives new terminals
hello-world “Unable to find image … locally” Not an error. Docker is pulling from Hub. Second run is instant (cached)
nginx hang Terminal never comes back after docker run nginx Forgot -d. Ctrl+C, then docker run -d -p 8080:80 nginx
8080 Browser can’t load the page WSL: Windows browser at localhost:8080. SSH: VS Code Ports tab. Anyone: curl localhost:8080
ps empty “My container disappeared” docker ps = running only. Stopped containers live in docker ps -a
rm / rmi Can’t delete the image Stop + docker rm the container first, then docker rmi the image
sidebar Still empty / Failed to connect Wrong environment — bottom-left must say WSL: Ubuntu or SSH: … (same place Engine lives)
