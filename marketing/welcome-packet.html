Agentic Coding

From first terminal command to shipping an AI‑assisted, full‑stack application.
Hybrid & self-paced in D2L Brightspace  ·  Live blocks Mon + Wed, 6:00–8:00 PM

Welcome to Agentic Coding! Over the next 18 weeks you'll go from "I've never touched a terminal" to building and shipping a real web application with an AI coding assistant working alongside you. You'll master VS Code, the Linux command line, Docker, FastAPI, and Git/GitHub — then put those skills to work with Continue.dev running against Temple College's own AI server. No cloud fees, no GPU required: everything runs on your laptop plus the college's shared infrastructure.

The course is self-paced. Every lesson opens with a short concept video and ends with a hands-on lab you complete on your own machine; submitting the lab unlocks the next lesson. Twice a week we meet live — Monday I teach the week's material, Wednesday is a lab clinic where we fix whatever is blocking you. Come to both whenever you can, and move at your own speed either way.

Two things to do before your first live block: complete the 5-minute survey below, and confirm your laptop meets the requirements on page 2.

What your computer needs

Everyone: a 64-bit laptop with 8 GB RAM (16 GB recommended), 30 GB free disk space, reliable internet, and administrator rights to install software. A free GitHub account is needed by week 10 (github.com — you can create it now). No GPU required — the AI models run on the college's shared server (2× RTX A6000); your laptop just connects to it.
Windows Windows 10 / 11 + WSL2
  • Windows 10 (version 2004, build 19041, or later) or any Windows 11.
  • WSL2 with Ubuntu — we install it together in Module 00. Expect one reboot; installing ahead of week 1 saves class time.
  • Hardware virtualization enabled in BIOS/UEFI (usually already on; we'll help if Windows prompts you).
  • Docker and all Linux labs run inside WSL2 — your files and terminal live there for the whole course.
  • Alternative: if WSL2 won't work on your machine, you can do the entire course over SSH into the college's Linux server (set up in Module 00).
Mac macOS — Apple Silicon or Intel
  • macOS 12 Monterey or later — both Apple Silicon (M1/M2/M3/M4) and Intel Macs are fine.
  • Uses the built-in Terminal — no WSL or extra setup needed to get a Unix shell.
  • VS Code, Docker Desktop, and all developer tools install natively on macOS.
  • For the Ubuntu-specific drills (apt, services), Mac students connect to the college's Linux server over SSH (set up in Module 00).
Not supported: Chromebooks and tablets (including iPads). This course lives in a real Linux/Unix shell throughout — you need a laptop you can install software on.

What you'll build, module by module

Module 00 · 8 lessons

VS Code & IDE Fundamentals

Your editor for the whole course: UI, command palette, integrated terminal, extensions, and remote connections over WSL and SSH.

Module 01 · 12 lessons

Ubuntu Terminal Fundamentals

Navigate, create, and inspect files; sudo & package installs; permissions; networking; processes; pipes & grep; users & groups.

Module 02 · 7 lessons

Docker Fundamentals

Install Docker, run your first containers, understand images vs containers, and manage everything from the VS Code sidebar.

Module 03 · 13 lessons

FastAPI Development

Build a real Python API: routes, validation with Pydantic, dependency injection, then containerize it with a Postgres database.

Module 04 · 12 lessons

Git & GitHub

Version control from first commit to branches, pushing to GitHub over SSH, and reviewing classmates' pull requests.

Module 05 · 10 lessons

AI Coding with Continue.dev

Connect VS Code to the college's AI server: chat with codebase context, autocomplete, inline edits, and agent mode.

Module 06 + Capstone · 8 lessons

HeroUI Frontend & Final Project

Put a modern React/Next.js interface on top of your own API — built with AI assistance — then combine everything into a capstone feature you demo at the final session.

Before your first live block

  • Complete the pre-course survey — tktechventure.com/agentic-coding (5 minutes; helps us prep for your exact machine).
  • Check your laptop against the Windows / Mac requirements on page 2.
  • Windows students: if you're comfortable, install WSL2 + Ubuntu ahead of time (it needs a reboot) — otherwise we'll do it together in week 1.
  • Create a free GitHub account at github.com — not needed until week 10, but easiest to do now.
  • Log in to D2L Brightspace and confirm you can see the course.
