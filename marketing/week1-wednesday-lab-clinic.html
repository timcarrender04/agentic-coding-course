Module 00 · VS Code Walkthrough

Stuck-spot cheat sheet

MomentWhat failsFix line
Install No admin / locked laptop Put name in chat — alternate path (SSH lab machine) later
Sign-in Sync settings prompt Skip — optional cloud sync. You never need to sign in for Phase 1
Palette Mac hitting Ctrl Mac = Cmd tonight (Cmd+Shift+P)
Terminal Typing in editor / no backtick Click the bottom panel; or View → Terminal
Docker “Failed to connect” Correct — Docker Engine is Module 02. Extension only tonight
WSL Needs reboot / password blank Reboot after install; password typing is invisible — keep typing
Excited 10 random extensions Only Python + Docker (+ WSL / Remote SSH). Continue.dev comes later
