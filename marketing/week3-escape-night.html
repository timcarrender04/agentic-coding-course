Terminal Escape Night

"Lockdown at ChiefOS" · Module 01 culminating event
Four locked rooms. One dead GUI. Everything you learned this week is the key.
Wed Aug 5  ·  6:00–8:00 PM  ·  Zoom  ·  3 Teams  ·  4 Rooms

Tonight replaces the lab clinic with a race. A bad update has locked every door in the ChiefOS server building — mouse dead, GUI dead, terminal only. Three teams, each in its own Zoom breakout room, fight through four escape rooms. Every room is secretly a Week 3 lab in disguise: navigation, cp/mv/rm -r, less/tail -f/nano, and the boss fight — permissions. Escape the building and you've re-run labs 01:02–06 without noticing.

How the race works
  • Everyone types on their own machine — no passengers
  • A room counts as cleared only when every member has its code word
  • Roles rotate each room: Driver (shares screen, types), Reader (reads files aloud), Scribe (tracks code words, posts clears)
  • Scribe posts clears in main chat: SUDO cleared Room 2 — NOUNDO
  • Teammates who escape early coach the rest — words only, no typing on anyone else's machine
Winning & hints
  • Winner: first team with every member through the final door — banner screenshots in chat prove it
  • Each team gets 3 hint tokens — spend one to summon the instructor for a nudge
  • Tiebreaker: fewest hint tokens spent
  • First hint is always free advice: read the room's files again — the answer is written down. It always is.

Before class checklist

Setup
  • Post setup.sh where students can grab it: D2L file, Zoom file transfer, or course site (curl -O = lab 01:07 stretch tie-in)
  • Students run it as themselves — never with sudo; it prompts for sudo once at the end to seal the vault
  • sudo fails for someone? Game still works (chmod-000 fallback) — don't burn time on it
  • Dry-run it yourself: bash setup.sh --reset
Zoom
  • Pre-create 3 breakout rooms named SUDO / NANO / CHMOD
  • Balance teams: each gets at least one lab-01:02–05 cruiser and one struggler
  • Use broadcast to all rooms for milestones — "NANO has entered the vault…" keeps the race live
  • Leaderboard doc or whiteboard shared in the main room
