You Are Here

One download · the whole crew walks it
The directory signs fell off. WSL or Mac. Prove where you are.
Wed  ·  6:00–8:00 PM  ·  Zoom  ·  Crews of 3

Tonight is one lab, done as a group. Everyone downloads the same setup.sh, builds the building on their own machine, and a crew of three walks it together. Six floors, then you say what the machine will print before it prints it, then a banner. A floor counts only when all three have its fragment. WSL and Mac both work. SSH is not part of tonight. The only commands inside are pwd, ls, ls -la, cd, cd -, hostname, whoami, and uname.

Before 6:00 — build, don't explore
  • Download setup.sh

  • Stop there. cat README.txt waits for the clock

How a crew of 3 clears a floor
  • Cameras on. Think out loud. Words only — never type on someone else's machine
  • Scribe posts in main chat: CREW 2 — floor 4 (3/3)
  • Floors stay shut until all three finish join.sh and type each other's badges
  • Finished early? Coach the other two until their banners match
  • 3 hint tokens for the night. First hint is always: read the floor again
  • Winner: first crew with three banners in chat. Tiebreaker: fewest hints

Answer key

FloorWhat they actually doWord
Roll call bash ~/you-are-here/join.sh. Same crew name on all three. Seats 1, 2, 3. Each reads hostname, whoami, and badge. The others type what they heard. A solo machine cannot invent a second seat. --redo if the crew name was wrong. lock
1 · Wrong Door cd windows-side · cat Users/Documents/EMPTY.txt · bash look.sh · cd .. · bash stamp.sh. Lesson: files didn't vanish; /mnt is the Windows drive; Mac home is /Users. HERE
2 · Home Button Bare cd (no path, no tilde). bash ~/you-are-here/home-button/stamp.sh only passes when pwd is $HOME. BARE
3 · Dotfile ls -la · cat ~/.you-are-here · bash ~/you-are-here/dotfile/stamp.sh .bashrc (any real dotfile except the planted note). Mac: .zshrc or .zsh_history. DOT
4 · Stairs From the stairs, same terminal: cd /tmp · bash drop.sh · cd - · bash stamp.sh. Crew enforces "don't retype the path." Mac /private/tmp counts. HOP
5 · Route bash scout.sh at home → /etc → /usr → home → /, in that order. Scout prints the next stop. ROUTE
6 · Callback Seat 1's card is only /etc, seat 2 only /usr, seat 3 only /var. They read their own path aloud. Everyone still types all three, with bare cd and home.sh between calls. BACK
Front desk bash ~/you-are-here/predict.sh — say hostname, whoami, pwd, uname -a, then Enter. Linux → say WSL. Darwin → say Mac. SAID
Banner bash ~/you-are-here/banner.sh lists every fragment plus machine, user, and pwd. All three screenshots in chat. banner

When they get stuck

They sayWhat to tell them
Badge Crew ids differ, or they typed this machine. Have each seat re-read hostname, whoami, and badge. bash ~/you-are-here/join.sh --redo if the name was wrong.
Windows Setup refuses anything that isn't Linux or Darwin. Open the Ubuntu app, not Command Prompt.
No note ls hides it. ls -la from home. The name contains you-are-here.
Not home They typed a path. Two letters: cd. Then run the stamp again.
Stairs Second terminal forgot the hop. One terminal: cd /tmp, then cd -. /private/tmp on a Mac is the same room.
Route Scout names the next stop and prints pwd. bash scout.sh --reset starts the five over.
Callback They marked two floors without coming home. bash home.sh --reset, then one call at a time.
Mess bash setup.sh --reset deletes ~/you-are-here and the hidden note, then rebuilds.
