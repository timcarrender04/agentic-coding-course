Block B · Lessons 00–01 (6:25–6:55)

00 · What is an IDE? · install VS Code

~15 min
Before we touch any code, three words: editor, terminal, IDE. By the end of this block VS Code is installed and open on your laptop.
  • Editor — type and save text (Notepad / TextEdit)
  • Terminal — type commands, computer runs them (Command Prompt / Terminal app)
  • IDE — editor + terminal + tools in one window. VS Code is an IDE.
VS Code is free and won’t force you to sign in. If it offers “Sign in to sync settings,” skip it. Our AI comes later in Module 05 via Continue.dev — nothing to buy tonight.
Show Notepad → Terminal → your open VS Code, same task in all three.
Do Start downloads early (~100 MB). Talk while it installs.
  • Browser → code.visualstudio.com → Download for your OS
  • Run installer · accept defaults · open VS Code
  • Mac: replace every Ctrl with Cmd for the rest of the night
Done when: VS Code welcome screen is open. Hands up if install fails — do not move on without them.

01 · VS Code UI tour

~15 min
Activity bar is the thin icon strip on the left edge. Sidebar is the panel that opens when you click an icon. Don’t mix the names.
  • Activity bar · Explorer · editor tabs · status bar
  • Command palette — Ctrl+Shift+P (Cmd+Shift+P on Mac). Drill it. If they remember one shortcut, this is it.
  • Settings: gear or palette → “settings”
Stuck spot: Student’s UI looks different (theme/panels). Note it; don’t rebuild their layout in class.
Done when: Student can open command palette on demand and point to activity bar vs sidebar.
6:55 · Break · 5 min

Help remaining installs. Remind Windows students: no WSL reboot tonight.

Block C · Lesson 02 (7:00–7:30)

02 · Integrated terminal

~25–30 min
A terminal is where you type a command, press Enter, and get text back. VS Code’s integrated terminal is the same thing — embedded so you never alt-tab away.
  • Open with Ctrl+` (backtick under Escape), or View → Terminal, or command palette
  • Click inside the terminal panel (not the editor)
  • Type echo hello → Enter → should print hello
  • Again with their name · close · reopen · output still there
Stuck / done: No backtick → View → Terminal. Typing in editor → point at panes. Don’t teach cd/ls (Module 01). Done when echo hello prints in the terminal (D2L screenshot if required).
