## Narration

[warm and friendly] Out of the box, VS Code is a general-purpose IDE — it doesn't know Python from a hole in the ground. Today we fix that with extensions. And just as important, we learn how to not install the wrong one. [break]

[calm] An extension is a plugin that adds features to VS Code. One might add Python support, another a Docker sidebar, another a way to connect to a remote computer. You install only what you need, and they all come from one big public catalog called the marketplace. It's built right into the IDE — you get to it from the extensions icon in the activity bar, the four squares with one floating away, or with control shift X. [break]

[calm] Two things to know before you click Install on anything. First, check the publisher. Anyone can publish to the marketplace, so there are multiple extensions called Python — the one we want is by Microsoft. Always read the publisher name under the title before you install. Second, the button on an extension has three states: Install when you don't have it, Uninstall when you do, and Disable, which turns it off without removing it — handy when an extension is misbehaving but you'll want it back later. [break]

[confident] Here's your lab. Open the extensions side bar with control shift X, search for Python, verify the publisher says Microsoft, and click Install. Then scroll the side bar down to the installed section and confirm Python is listed there. And that's it — one extension. I know the marketplace is fun to browse, but don't install random extras today. We'll add Docker and the remote extensions later this module, and our free AI extension, Continue, comes in Module five. [long-break]

[encouraging] You're done when Python by Microsoft shows under the installed section of your extensions side bar. Take a screenshot of that side bar with Python installed and the publisher visible, and submit it in D2L. If you grabbed a different Python by mistake, uninstall it and get the Microsoft one. Then open the lesson and work through it. I'll see you in the next one.
