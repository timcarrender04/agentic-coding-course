## Narration

[warm and friendly] Hey, welcome back. VS Code is installed, so today we're learning the names of every part of that window. That might sound trivial, but here's the deal: once you know what each region is called, you can google your way out of any problem. Every answer online says things like click the icon in the activity bar, and if you don't know what an activity bar is, you're stuck before you've started. [break]

[calm] There are five regions to learn. The activity bar is the thin strip of icons on the very left edge of the window. The side bar is the wider panel that opens when you click one of those icons — that's where your file tree lives. The editor is the big middle area where files open as tabs. The panel is a horizontal strip at the bottom of the editor, hidden by default — the terminal is going to live there. And the status bar is the colored strip across the very bottom. Keep an eye on the bottom-left corner of that status bar. In lessons five and six, that corner is going to tell us which computer VS Code is connected to. [break]

[calm] One more thing, and it's the most important shortcut in the whole IDE: the [emphasis] command palette. [emphasis] Control shift P. If you're on a Mac, that's command shift P — and that goes for every shortcut in this module, control becomes command. The palette opens a search box where you can type the name of anything VS Code can do and just run it. If you only memorize one shortcut all module, make it this one. [break]

[confident] So here's your lab. Open a folder, any folder on your machine, and click a file so it opens as a tab. Use the [emphasis] command palette to toggle the terminal open, then toggle it closed again. Then open settings with control comma, search for font size, and change the editor font size to sixteen. [long-break]

[encouraging] You're done when your font size is sixteen and you can name all five regions out loud. Take one screenshot of your full VS Code window with your folder open and the settings tab showing font size sixteen, and submit it in D2L with the five region names typed in your comment. Then open the lesson and take the tour. I'll see you in the next one.
