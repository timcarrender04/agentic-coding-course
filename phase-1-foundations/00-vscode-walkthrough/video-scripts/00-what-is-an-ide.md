# Video: What is an IDE?

**Lesson:** [00-what-is-an-ide.md](../00-what-is-an-ide.md) · **Target:** ~2.5 min · **Words:** 373

## Narration

Hey, welcome to the course. Before we write a single line of code, I want to give you three words you're going to hear constantly: editor, terminal, and IDE. Get these three straight and everything else in this module falls into place.

First, an editor. An editor is just a program that lets you type text and save it into a file. Notepad on Windows. TextEdit on a Mac. That's the whole job. No magic.

Second, a terminal. A terminal is a program where you type commands as text, and the computer runs them. No buttons, no menus. Text in, text out. If you've ever seen Command Prompt on Windows, or the Terminal app on a Mac, that's a terminal.

And third, the IDE. IDE stands for Integrated Development Environment, and it's exactly what it sounds like. An editor, plus a terminal, plus a pile of other tools, all bolted together into one window. The whole point of an IDE is that you don't alt-tab between five programs just to write and run your code.

The IDE we're using for this entire course is VS Code. Visual Studio Code, made by Microsoft. It's free, and it's one of the most used IDEs in the world. That popularity matters, because when you google how to do something in VS Code, the answer will match exactly what's on your screen.

One thing VS Code does not have out of the box is an AI assistant, and that's on purpose for now. In module five we'll add Continue dot dev, a free extension wired to the college's shared model server. Today is just the IDE itself.

So here's your lab. Go to code dot visualstudio dot com, download VS Code for your operating system, run the installer, and accept the defaults. When it opens you'll land on a Welcome tab. Pick a color theme if you like. And if it offers to sign you in to sync settings, skip it. You never need to sign in for this course.

You're done when VS Code is open on that welcome screen. Take a screenshot of the whole window and submit it in D2L, with a one-sentence definition of an IDE in your own words. Then open the lesson, and I'll see you in the next one.
