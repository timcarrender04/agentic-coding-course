Module 01 — Ubuntu Terminal Foundations

🎯 What you'll be able to do after this module
  • Navigate the Linux filesystem confidently using pwd, ls, and cd
  • Create, copy, move, rename, and delete files and directories from the terminal
  • Read and edit files from the terminal using cat, head, tail, less, nano, and output redirection
  • Update an Ubuntu system and install packages with apt using sudo
  • Interpret and modify file permissions and ownership with chmod and chown
  • Diagnose basic network connectivity and DNS with ping, curl, dig, and ss
  • Inspect running processes and service status with ps, top, systemctl, and journalctl
  • Chain commands with pipes and grep, and manage users and groups in preparation for the docker group

Lessons and objectives

#LessonLearning objective
00Setup CheckVerify that the Ubuntu environment is course-ready by checking the OS release, internet connectivity, DNS resolution, and sudo access.
01Where Am I?Navigate the filesystem without hesitation using pwd, ls, cd with absolute paths, cd -, and the ~ home shortcut.
02Making ThingsCreate the ~/docker-course working directory and practice creating, copying, moving, renaming, and deleting files and directories with mkdir, touch, cp, mv, and rm.
03Looking Inside FilesCreate, read, and edit files from the terminal using echo with > and >> redirection, cat, head, tail, less, wc -l, and nano.
04Sudo and System UpdatesPerform a full system update with sudo apt update, sudo apt upgrade -y, and sudo apt autoremove -y.
05Installing SoftwareInstall and verify the Docker prerequisite packages (curl, wget, git, htop, tree, ca-certificates, gnupg) using sudo apt install.
06Permissions DrillsRead permission strings and change file permissions and ownership using chmod in symbolic and numeric forms and chown with sudo.
07Networking DrillsDiagnose network readiness for Docker Hub using ip a, ping, curl, ss -tuln, and dig.
08Processes and ServicesInspect running processes and service status using ps aux, top, htop, systemctl, journalctl, uptime, free -h, and df -h.
09Pipes and GrepChain commands together with pipes and search files using grep (including -v, -i, and -r), wc -l, cut, sort, and uniq.
10User and Group SetupInspect user and group membership with id and groups, add a user to a group with sudo usermod -aG, and refresh group membership with newgrp.
11Final CheckpointDemonstrate every skill from the module by running the cumulative command drill from memory to prove the environment is ready for Docker installation.

Each lesson is one learning object with a paired lab. Work in order — completing a lab unlocks the next lesson. The module ends with a Check on Learning quiz and a hands-on final checkpoint.
