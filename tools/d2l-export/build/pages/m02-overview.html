Module 02 — Docker Installation and First Containers

🎯 What you'll be able to do after this module
  • Install Docker Engine from the official Docker apt repository, including the GPG key and repository setup
  • Add your user to the docker group so Docker commands run without sudo
  • Run docker run hello-world and explain the pull, create, run, and exit sequence Docker performs
  • Run an nginx container in detached mode with a port mapping and reach it from a browser
  • Distinguish images from containers and clean up both with docker rm, docker rmi, and the prune commands
  • Manage and inspect containers and images from the VS Code Docker sidebar

Lessons and objectives

#LessonLearning objective
00Setup CheckVerify the Ubuntu environment is ready for Docker installation by checking Linux, sudo, the curl and gpg packages, network reachability of Docker Hub, and free disk space.
01Install Docker EngineInstall Docker Engine from the official Docker apt repository and add your user to the docker group so docker info works without sudo.
02Your First ContainerRun the hello-world container and explain the six steps Docker performed, from pulling the image off Docker Hub to the container exiting.
03Running a Real ImageRun an nginx web server as a detached, port-mapped, named container, reach it from a browser, and inspect it with docker logs and docker exec.
04Images vs ContainersDistinguish images from containers by running multiple containers from one image, then clean up both with docker rm, docker rmi, and the prune commands.
05The VS Code Docker SidebarManage containers and images from the VS Code Docker sidebar, including stopping, removing, viewing logs, and attaching a shell via the right-click menu.
06Final CheckpointDemonstrate module mastery by running, verifying, and cleaning up a named detached nginx container end-to-end without instructor help.

Each lesson is one learning object with a paired lab. Work in order — completing a lab unlocks the next lesson. The module ends with a Check on Learning quiz and a hands-on final checkpoint.
