Module 06 — HeroUI Frontend

🎯 What you'll be able to do after this module
  • Install Node.js with nvm and confirm node, npm, and npx resolve to nvm-managed paths
  • Initialize a HeroUI starter project with Next.js and Tailwind pre-configured and run its dev server with hot reload
  • Build interactive pages using HeroUI components such as Button, Input, Card, and Checkbox, applying the "use client" directive where hooks are used
  • Enable CORS in the FastAPI backend with CORSMiddleware so the browser-based frontend can call it
  • Fetch items from http://localhost:8000/items and render them as HeroUI Cards with loading, error, and empty states
  • Build a form that POSTs new items to the API and refreshes the displayed list inline without a page reload
  • Use Continue.dev chat, inline edit, and agent mode to extend the frontend, reviewing every proposed diff before accepting
  • Ship a frontend change through a branch, commit, and merge or GitHub PR workflow

Lessons and objectives

#LessonLearning objective
00Prerequisites CheckVerify that the FastAPI Compose stack, Continue.dev connection, and GitHub remote from earlier modules still work and that no conflicting system Node.js installation is present.
01Install Node.js with nvmInstall nvm and the latest LTS release of Node.js, set it as the default, and confirm node, npm, and npx run from nvm-managed paths under your home directory.
02Init the HeroUI AppScaffold a Next.js + HeroUI starter project with npx heroui-cli@latest init, install its dependencies, and run the dev server so the starter page loads on port 3000.
03Tour + First ComponentBuild an interactive homepage from HeroUI Button, Card, and Input components and explain when a Next.js page needs the "use client" directive to use React hooks.
04CORS + Fetch ItemsAdd CORSMiddleware to the FastAPI backend and fetch the items list from the browser, rendering each item as a HeroUI Card with loading, error, and empty states.
05Create-Item FormBuild a HeroUI form that POSTs new items to FastAPI, converts input strings to the types the API expects, surfaces server validation errors, and reloads the list inline on success.
06Extend with Continue.devUse Continue.dev agent mode on a git feature branch to add a Delete button with a confirmation modal, reviewing every proposed diff and recognizing when to abort a failing agent loop.
07Final CheckpointShip a client-side, case-insensitive search filter for the items page end-to-end using Continue.dev, verify it in the browser, and commit and merge the change.

Each lesson is one learning object with a paired lab. Work in order — completing a lab unlocks the next lesson. The module ends with a Check on Learning quiz and a hands-on final checkpoint.
