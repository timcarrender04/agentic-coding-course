Module 00 — VS Code Walkthrough

🎯 What you'll be able to do after this module
  • Explain what an IDE is and how VS Code combines an editor, a terminal, and other tools in one window
  • Navigate the VS Code UI, naming the activity bar, side bar, editor, panel, and status bar, and run commands from the command palette
  • Open the integrated terminal and distinguish typing into the terminal from typing into the editor
  • Install, disable, and uninstall extensions from the marketplace, verifying the publisher before installing
  • Install the Docker extension and explain why its sidebar is empty before Docker itself is installed
  • Connect VS Code to WSL on Windows and open a folder in the Linux home directory
  • Connect VS Code to a remote machine over SSH, open a remote folder, and verify the terminal runs on the remote

Lessons and objectives

#LessonLearning objective
00What is an IDE?Install VS Code and explain the difference between an editor, a terminal, and an IDE.
01VS Code UI TourIdentify the activity bar, side bar, editor, panel, and status bar, and use the command palette (Ctrl+Shift+P) to toggle the terminal and change the editor font size.
02The Integrated TerminalOpen the integrated terminal, run echo commands at the prompt, and distinguish typing into the terminal from typing into the editor.
03Extensions OverviewInstall the Python extension by Microsoft from the marketplace, verify its publisher first, and describe when to use Install, Disable, and Uninstall.
04The Docker ExtensionInstall the Docker extension by Microsoft, locate its whale icon and sidebar sections, and explain why the sidebar shows 'Failed to connect' before Docker is installed.
05Connecting to WSLConnect VS Code to WSL using the WSL extension, open a folder in the Linux home directory, and verify the terminal is Linux by running uname -a.
06Connecting over SSHConnect VS Code to an instructor-provided remote host with the Remote - SSH extension, open a remote folder, and confirm the session by running hostname and whoami.
07Final CheckpointDemonstrate unaided use of VS Code by toggling the terminal from the command palette, installing an extension, connecting to WSL or SSH, and capturing a screenshot showing the green remote indicator with whoami and pwd output.

Each lesson is one learning object with a paired lab. Work in order — completing a lab unlocks the next lesson. The module ends with a Check on Learning quiz and a hands-on final checkpoint.
