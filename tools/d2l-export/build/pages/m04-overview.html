Module 04 — Git and GitHub

🎯 What you'll be able to do after this module
  • Configure Git globally with user.name, user.email, and init.defaultBranch set to main
  • Initialize a repository and manage changes through the status / add / commit cycle with descriptive commit messages
  • Inspect changes and history confidently using git status, git diff, and git log with their most useful flags
  • Create, switch, merge, and delete branches, distinguishing fast-forward merges from true merge commits
  • Recover from common mistakes using git restore, git restore --staged, git commit --amend, and git reset
  • Generate an ed25519 SSH key, register it with a GitHub account, and push a local repository to a GitHub remote
  • Clone a repository from GitHub, pull updates, and resolve a merge conflict by hand
  • Open a pull request on GitHub, review and respond to inline comments, and merge it back to main

Lessons and objectives

#LessonLearning objective
00Prerequisites CheckVerify that Git is installed and the Module 03 FastAPI project exists with no pre-existing .git directory.
01Configure GitConfigure Git globally with user.name, user.email, init.defaultBranch=main, and pull.rebase=false, then verify the settings stored in ~/.gitconfig.
02Init and First CommitInitialize a Git repository in the FastAPI project, extend .gitignore, stage everything with git add ., and make a first commit on main.
03The status / add / commit CycleMake a series of commits using the edit, git status, git add, git commit cycle, including selective staging and the -am shortcut's untracked-file limitation.
04Diff and LogInspect unstaged, staged, and between-commit changes with git diff and read history with git log filters such as --oneline, --graph, --author, and --grep.
05BranchesCreate and switch branches with git switch, merge a feature branch into main via both a fast-forward and a true merge commit, and delete merged branches with git branch -d.
06Undoing ThingsUndo common mistakes by discarding edits with git restore, unstaging with git restore --staged, amending the last commit with git commit --amend, and removing a commit with git reset.
07GitHub Account and SSH KeyGenerate an ed25519 SSH key with ssh-keygen, register the public key in GitHub's settings, and verify passwordless authentication with ssh -T.
08Pushing to GitHubConnect a local repository to a GitHub remote with git remote add origin, push it with git push -u origin main, and round-trip commits between the terminal and the web UI with git push and git pull.
09Cloning, Pulling, and ConflictsClone a repository from GitHub, sync changes between two working copies with git pull, and resolve a merge conflict by editing out the conflict markers, staging the file, and committing the merge.
10Pull RequestsPush a feature branch to GitHub, open a pull request, leave and respond to inline review comments, merge the PR with a merge commit, and sync the result to the local main.
11Final CheckpointComplete a full branch, commit, push, pull request, review, and merge cycle from memory and verify the new /info route works end to end.

Each lesson is one learning object with a paired lab. Work in order — completing a lab unlocks the next lesson. The module ends with a Check on Learning quiz and a hands-on final checkpoint.
