Module 03 — FastAPI from Scratch

🎯 What you'll be able to do after this module
  • Create and activate a Python virtual environment with python3 -m venv and pin project dependencies in a requirements.txt
  • Build FastAPI routes (GET, POST, DELETE) that use typed path parameters, query parameters, and JSON request bodies
  • Validate request data with Pydantic models and interpret FastAPI's automatic 422 validation errors
  • Organize a growing application into per-resource routers using APIRouter prefixes and tags
  • Implement shared logic such as header-based authentication and database sessions with Depends dependency injection
  • Containerize the app with a Dockerfile and run it alongside Postgres using Docker Compose with healthchecks and named volumes
  • Persist data to Postgres using SQLAlchemy ORM models, an engine, and per-request sessions
  • Return correct HTTP status codes with HTTPException and verify every endpoint with both curl and the /docs Swagger UI

Lessons and objectives

#LessonLearning objective
00Prerequisites CheckVerify that Python 3, pip, Docker (without sudo), Docker Compose, curl, and the course directory from Modules 01 and 02 all still work before starting FastAPI.
01Python Virtual EnvironmentCreate, activate, and deactivate a project-scoped virtual environment with python3 -m venv and explain when to use a venv on the host versus running in Docker.
02Installing FastAPIInstall FastAPI and Uvicorn into the active venv and freeze the exact package versions into a requirements.txt with pip freeze.
03Hello WorldWrite a minimal FastAPI app in main.py, run it with uvicorn main:app --reload, and verify responses from curl, a browser, and the /docs Swagger UI.
04Path and Query ParamsDefine routes with typed path parameters and optional query parameters, and demonstrate FastAPI rejecting mistyped input with 422 validation errors.
05Request Bodies with PydanticValidate JSON request bodies on a POST /items route with a Pydantic BaseModel and test valid and invalid payloads from both curl and Swagger UI.
06Multiple Routes and RoutersRefactor routes into per-resource modules using APIRouter with prefixes and tags, and mount them in main.py with app.include_router.
07Dependencies and InjectionImplement a header-checking get_current_user dependency with Depends and apply it at route level and router level, distinguishing 401 and 422 responses.
08Containerizing FastAPIWrite a Dockerfile that caches the pip-install layer, build the image, and run the containerized app with uvicorn bound to 0.0.0.0 so the mapped port is reachable.
09Docker Compose and PostgresOrchestrate the FastAPI app and a Postgres database with docker-compose.yml, using a healthcheck, a named volume, a bind-mounted hot-reload dev loop, and a .env file for secrets.
10Database with SQLAlchemyReplace the in-memory item store with Postgres persistence using a SQLAlchemy engine, ORM models, and a get_db session dependency, then verify the rows directly in psql.
11Error Handling and Status CodesReturn correct HTTP status codes (201, 204, 400, 404) by setting status_code on route decorators and raising HTTPException for missing resources and business-rule violations.
12Final CheckpointBuild a complete Profile resource from memory — SQLAlchemy model, router, protected DELETE, and correct status codes — and pass a 10-step curl acceptance test.

Each lesson is one learning object with a paired lab. Work in order — completing a lab unlocks the next lesson. The module ends with a Check on Learning quiz and a hands-on final checkpoint.
