Week 18 — Capstone

🎯 Learning objective: Combine a FastAPI backend, a HeroUI frontend, and AI-assisted development with Continue.dev into one working, demonstrated application.

The capstone is the only week with no new content. You apply everything from the previous 17 weeks.

The task

  1. Backend: a FastAPI service (from Module 03) running in Docker Compose with Postgres — at least one resource with create and list endpoints.
  2. Frontend: a HeroUI app (from Module 06) that fetches from and posts to your API.
  3. AI-assisted: use Continue.dev against the hosted model (Module 05) to add one feature you haven't built before — e.g. delete/edit, search, or validation. Keep the chat/edit transcript.
  4. Version control: the whole project lives in a public GitHub repo (Module 04) with a meaningful commit history and at least one merged pull request.

Submit

  • The GitHub repository link.
  • A short screen recording or screenshots of the app working end to end.
  • One paragraph: what you asked the AI to do, what it got right, and what you had to fix.
🧪 Demo. Present your capstone at the final weekly Zoom session.
