Lesson 00: What is an IDE?

Time: ~15 min

Concepts

Before we install anything, three words you'll hear all day:

  • Editor — a program that lets you type and save text into a file. Notepad on Windows, TextEdit on Mac. That's it. No magic.
  • Terminal — a program where you type commands as text and the computer runs them. No buttons, no menus. Just text in, text out. The Windows "Command Prompt" and the Mac "Terminal app" are both terminals.
  • IDE — short for Integrated Development Environment. It is an editor and a terminal and a bunch of other tools, all bolted together in one window. The whole point of an IDE is that you don't have to alt-tab between five different programs to write, run, and debug code.

VS Code is an IDE. VS Code (Visual Studio Code, made by Microsoft) is one of the most widely used IDEs in the world. Because it's so popular, if you ever google something like "how do I do X in VS Code" the answer will match exactly what's on your screen.

A note on AI for this course: Out of the box, VS Code has no AI assistant — it's just the editor. In Module 05 we'll install Continue.dev, a free, open-source extension that gives you the same agentic-coding features (chat, inline edit, autocomplete) powered by the college's shared LLM server. Today we just want the IDE itself. If VS Code offers to "Sign in to sync settings," that's optional cloud sync and unrelated — skip it.

Demo (instructor at the front)

The instructor will show:

  1. Notepad (or TextEdit) — just an editor.
  2. Command Prompt (or Terminal app) — just a terminal.
  3. VS Code — both, plus more, in one window.

You will see how the same task ("write a file, then run it") looks in all three.

Hands-on: install VS Code

  1. Open your normal web browser.
  2. Go to code.visualstudio.com.
  3. Click Download for your operating system (Windows / Mac / Linux).
  4. Run the installer. Accept the defaults.
  5. Launch VS Code.

When VS Code first opens you'll land on a Welcome tab. It may offer to:

  • Choose a color theme. Pick whichever you like. Light or dark — your eyes, your call.
  • Sign in to sync settings. This is optional cloud sync of your settings across machines. Skip it for the whole course — you don't need it.
  • Get Started walkthroughs. VS Code shows a few "getting started" tips on the Welcome tab. Feel free to close them — we'll cover everything you need as we go.

The shortcuts in the rest of this module assume VS Code's default keybindings, which is what you get out of the box. You don't need to change anything.
